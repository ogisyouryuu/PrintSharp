# 使用示例

本分区提供仓库中已有示例的入口。示例依赖模板文件和项目代码时，请从仓库根目录按其 README 或项目说明运行。

## 现有示例

- [WinForms Demo 使用说明](https://github.com/ogisyouryuu/PrintSharp/blob/main/demos/PrintSharp.WinForms.Demo/README.md)：Windows 窗体演示及当前报表操作说明。
- [API 请求示例](https://github.com/ogisyouryuu/PrintSharp/blob/main/src/PrintSharp.Api/README.md)：包含 PDF、XLSX 的 curl 与 HttpClient 请求示例。
- 多语言控制台示例：项目位于 `demos/PrintSharp.Multilingual.Demo`，共用数据样例位于 `demos/Shared/MultilingualSamples.cs`。

## 当前覆盖范围

仓库包含 Excel 模板绑定、PDF 输出、Windows 打印和 HTTP 服务的演示或测试用例。此分区暂不复制大量代码样例；具体 API 行为以现有项目 README、源代码和测试为准。新增示例时应确保模板文件和命令能在干净检出中复现。
