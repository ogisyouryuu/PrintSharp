# 架构决策

本页是架构决策记录（ADR）索引。当前没有在本页追认未经确认的历史决策；已有迁移记录仍按原文保存并标明来源。

## 决策记录约定

每条 ADR 至少记录：

- **背景**：需要作出选择的问题和约束。
- **决策**：采用的方案。
- **理由**：方案如何满足需求。
- **替代方案**：考虑过的其他选择及未采用原因。
- **影响**：收益、代价、迁移或兼容性影响。
- **状态**：提议、已接受、已弃用或已取代。
- **日期**：决策日期，使用 `YYYY-MM-DD`。

## 新 ADR 模板

新建记录时可复制以下结构，并根据维护者确认的信息填写：

```markdown
# ADR-NNN：标题

- 状态：提议 / 已接受 / 已弃用 / 已取代
- 日期：YYYY-MM-DD

## 背景
## 决策
## 理由
## 替代方案
## 影响
```
